# F7Zip

基于 Flutter 与 7-Zip 原生共享库的开源 macOS 压缩工具。界面沿用桌面压缩软件常见的工具栏、目录导航与文件列表交互。

## 立即运行

完成构建后的应用位于 `dist/F7Zip.app`，可直接双击或复制到应用程序文件夹。

```sh
open dist/F7Zip.app
```

当前构建面向本机 Apple Silicon 架构，最低 macOS 12。应用采用本地签名，尚未经过 Developer ID 签名及 Apple 公证。源码构建时使用当前 Mac 的架构。

## Finder 右键菜单

运行安装脚本将应用放到 `~/Applications/F7Zip.app` 并注册系统服务。

```sh
./scripts/install_macos.sh
```

在 Finder 中选中文件后，右键选择“服务”，使用以下入口。服务菜单的具体层级由 macOS 决定。

- “压缩为 ZIP（F7Zip）”直接在所选项目旁创建 ZIP，不打开主窗口和配置面板。单个项目使用完整文件名，多选使用 `Archive.zip`，重名时自动递增编号。
- “使用 F7Zip 压缩”打开主窗口，配置格式、压缩等级、加密方式和密码，再选择保存位置。
- “解压到当前文件夹（F7Zip）”直接解压到压缩包所在文件夹，不另建同名子文件夹。
- “解压到…（F7Zip）”弹出目录选择窗口，将内容解压到所选文件夹。多选压缩包共用该目标位置。
- 两个解压入口均支持加密压缩包，需要时单独弹出密码窗口，密码错误可重试或取消。已有同名顶层文件或文件夹时整包拒绝解压并提示，保留已有内容。
- “使用 F7Zip 打开”在主窗口浏览压缩包。

如果系统未展示菜单，可在“系统设置 → 键盘 → 键盘快捷键 → 服务 → 文件和文件夹”启用对应 F7Zip 服务。应用升级后重新打开以加载新版本。

## 已实现

- 创建 ZIP / 7z，选择压缩等级，可设置密码。ZIP 支持 AES-256（默认）或 ZipCrypto，7z 可选择是否加密文件名。
- 使用 7-Zip 26.00 的完整格式引擎浏览和解压 ZIP、7z、RAR、TAR、GZIP、XZ 等格式。
- 可展开的包内文件树，展示目录和文件，支持空目录、隐式父目录及与右侧列表联动。
- ZIP / 7z 内添加、重名确认替换、递归删除、重命名和新建文件夹，修改前验证版本，校验副本后原子替换。
- 包内目录导航、前进 / 后退、全包搜索、多选、全部解压、选中解压、快速解压到同级目录。
- 按名称、大小、压缩后大小、类型、时间排序，目录优先；属性显示压缩方法、CRC32、加密状态和已有归档注释。
- 紧凑分组工具栏、压缩包信息概览、28 像素行高的多列表格、可拖动宽度的文件树和可切换的目录树显示。
- 完整性测试、实时进度、后台任务和取消。
- 拖入压缩包打开，拖入普通文件或文件夹创建压缩包，已有可编辑包打开时添加到当前目录。
- Finder 右键“服务”菜单提供快捷 ZIP、配置压缩、原地解压、选择目录解压和打开，支持冷启动、密码重试和请求排队。
- 通过 Finder 的“打开方式”打开压缩包，以及在 Finder 显示处理结果。
- 可配置的隔行背景、单击 / 双击打开，以及 `..` 导航项。
- 可配置查看和编辑程序，ZIP / 7z 内文件在外部程序保存后自动回写。
- 后缀默认程序关联与恢复先前应用。
- 原生文件菜单及持久化最近文件列表（最多 8 项）。`⌘O` 打开、`⌘N` 新建、`⌘E` 解压、`⇧⌘A` 添加、`⇧⌘N` 新建文件夹、`⌘I` 属性、`⌘⌫` 删除、`F2` 重命名、`F3` 查看、`F4` 编辑、`⌘[` / `⌘]` 后退 / 前进、`⌘,` 设置，在文件列表中按 `⌘A` 全选。

主窗口内的解压会在目标位置创建以压缩包命名的新文件夹。重名时自动递增编号。任务使用私有暂存目录，成功后原子发布，失败和取消时清理暂存内容。已有文件不覆盖。选择保存到现有文件时，请在保存面板中改用新文件名。

“设置 → 常规”提供“解压时删除冗余的根目录”选项，默认关闭并记住选择。开启后，主窗口（含选中解压、快速解压）和 Finder 解压在结果只有一个顶层文件夹时去掉这一层，保留其内部目录结构。存在多个顶层项目或顶层为文件时保持原结构。处理在暂存目录内完成，仍保留同名冲突保护。

为避免递归压缩，压缩包需要保存到所选输入文件夹之外。当前解压会拒绝越界路径、符号链接和硬链接。

## 浏览设置与文件关联

点击右上角齿轮或按 `⌘,` 打开设置。外观支持跟随系统（默认）、浅色和深色，保存后立即生效并随重启保留。切换主题同步 macOS 窗口和系统文件面板外观，跟随系统时响应系统外观变化。配色使用 Material 3 的 `ColorScheme.fromSeed`，侧栏、导航、表头、列表及状态区使用对应语义色。常规设置中可选择经典紫（默认）、森林绿、青绿色、玫瑰粉、暖橙色和海洋蓝六组颜色主题，与明暗模式独立配置。选择时在设置窗口内预览，保存后全局生效并随重启保留，取消则保留原配色。欢迎页提供打开、新建及拖放提示，搜索支持一键清除。默认启用隔行背景、单击打开和 `..` 目录项，可在“常规”中切换，设置随应用重启保留。

文件列表中的勾选框用于多选。单击模式下点击文件名会打开文件，点击文件夹会进入目录。关闭单击模式后使用双击打开。仅在压缩包子目录显示 `..`，激活后返回包内上一级目录，根目录隐藏此项。导航项不参与全选和解压选择。

在“文件关联”中按后缀点击“设为 F7Zip”。支持 ZIP、7z、RAR、TAR、GZ、XZ、BZ2、ISO、TGZ、ZST、CAB、DMG、WIM、JAR、APK。macOS 会按需要要求确认。成功关联后可通过“恢复原应用”恢复此前的默认程序。

## 外部查看与编辑回写

在设置的“外部程序”页选择查看程序和编辑程序，支持 macOS `.app`，留空时使用系统默认程序。

- 单击或双击文件、工具栏“查看”和文件右键菜单均可打开查看程序。
- 勾选一个文件后点击“编辑”，或右键选择“编辑并自动回写”。
- 在编辑程序中保存当前文件，内容稳定后会自动更新对应 ZIP / 7z，并刷新列表。
- 底部“管理编辑文件”可定位工作文件、重试回写或结束监控。关闭管理窗口后继续自动回写。结束监控会保留工作文件。

编辑工作文件和恢复清单保存在 `~/Library/Application Support/F7Zip/EditSessions`。重启应用会恢复编辑会话，密码保留在内存中，恢复加密会话时通过“重试回写”重新输入密码。查看文件使用系统临时目录。

本应用添加和其他结构修改会接续未受影响编辑会话的版本。正在外部编辑的目标禁止被删除、重命名或替换。

回写会先锁定并验证原包、更新副本、校验结果，再原子替换。保留加密状态、原包其他条目、权限及扩展属性。原包被外部修改或发生写入错误时，应用保留工作文件并提示处理。

## 构建

需要 Flutter stable（Dart 3.13.7 或以上）、Xcode 命令行工具、Python 3.9+、Git 与网络连接。

```sh
./scripts/build_macos.sh
```

首次构建自动下载固定版本的 7-Zip 和 bit7z 源码，校验后编译。后续构建复用本地源码和中间文件。生成的原生库会由 Xcode 构建阶段自动嵌入应用，无需预先安装命令行 7-Zip。

```text
Flutter UI → Dart FFI → libf7zip.dylib（C++ / bit7z）→ 7z.so
```

开发运行前先构建原生库。

```sh
python3 scripts/build_native.py
flutter pub get
flutter run -d macos
```

Release 构建同时生成 `dist/F7Zip-sources.tar.gz`，包含自有代码和原始第三方源码，供开源发布及对应源码分发使用。

## 当前范围

当前版本 0.2.2。对照 Bandizip macOS 版，分卷创建、拖出解压、TGZ / TBZ 一步解包、TAR / TGZ / ZIPX 创建、文件名编码选择与自动检测、内置预览、注释编辑、压缩包修复及密码恢复仍待实现。Finder 工具栏扩展和批量任务队列也尚未实现。删除有确认和失败保护，成功删除后的撤销及原包备份尚未实现。当前打开分卷和其他特殊格式的能力取决于 7-Zip 引擎及输入完整性。

当前按 macOS 本地直接分发方式关闭 App Sandbox，文件选择使用系统面板。App Store 分发需要另外实现沙盒文件授权和持久访问。
